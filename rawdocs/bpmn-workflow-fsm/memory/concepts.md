# Concepts

## Core concepts

- Diagram as communication artifact
- Runtime semantics
- BPMN notation vs BPMN execution
- Statechart/FSM execution model
- Determinism and recoverability in workflows
- Durable execution
- Code-first workflow definition
- Governance vs implementation speed tradeoff

## Concept links

- Diagram clarity -> better cross-team alignment; not sufficient for execution.
- BPMN notation + engine -> executable business process orchestration.
- State + event + transition -> deterministic and testable runtime behavior.
- Durable execution + code-first workflows -> resume-safe long-running processes with CI/CD-friendly development.
- Governance-heavy environments -> BPMN-first planning can coexist with FSM/code-first runtime execution.
